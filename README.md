# Website notes

Quarto site served by GitHub Pages from `docs/` on `master` (https://codyvanzandt.com).
`docs/` is the built site: generated by `quarto render`, committed with the source.
Helper functions live in the `codytools` package (https://github.com/Codyvanzandt/codytools).

One-time setup, in `~/.Rprofile` (`C:/Users/codya/Documents/.Rprofile`):

```r
options(codytools.site = "C:/Users/codya/Desktop/personal-website")
```

## Add a post

```r
# In an analysis project:
cody_use()                                  # preview in the site's style
to_post(my_fig, "my-slug")                  # saves posts/my-slug/my_fig.rds

# Anywhere:
new_post("My *title*")                      # creates posts/my-title/index.qmd, or pass slug =
```

In the post: `from_post("my_fig")` (add `+ labs(...)` to tweak). Preview with Positron's
Preview button. Tables or other objects work with `to_post()` too; `as = "png"` saves a
plot exactly as drawn (use it for plots built on large data).

## Publish

```r
publish_site("Add post: My title")          # builds docs/, shows changes, commits, pushes
```

`build_site()` renders without publishing.

## Where things live

- `index.qmd`: homepage. `writing/index.qmd`: post listing. `cv/index.qmd`: CV.
- `posts/<slug>/`: one folder per post (`index.qmd` plus its saved plots).
- `_templates/post.qmd`: template for new posts. `_setup.qmd`: loads codytools in every post.
- `warm.scss`: site typography and colors. `fonts/`: fonts served by the site.
- `docs/`: built site. Don't edit by hand. `CNAME`: custom domain.
- `archive/hugo-site/`: the old Hugo site, kept for reference; not rendered.

One-time GitHub setting: Settings → Pages → deploy from branch `master`, folder `/docs`.
